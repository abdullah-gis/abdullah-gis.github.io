Leaflet / Web GIS / Spatial Data
Interactive Raster and Vector Data Viewer

An interactive Web GIS project for displaying and exploring vector and raster datasets. GeoJSON features can be clicked to view their attribute information, while georeferenced GeoTIFF raster layers can be displayed over an OpenStreetMap basemap.

Interactive Web Map
Select a GeoJSON or GeoTIFF file to display it on the map.
Supported files: vector data in .geojson or .json format and georeferenced raster data in .tif or .tiff format. Uploaded files are processed inside the browser and are not sent to a server.
